Vulnerability Description

The target host exposes SMBv1 on TCP port 445 and is vulnerable to MS17-010, an unauthenticated memory corruption flaw in Microsoft's SMBv1 handling[cite: 2]. Weaponized as "EternalBlue", this vector permits arbitrary kernel code execution without authentication or user interaction[cite: 2], famously leveraged during the WannaCry and NotPetya ransomware attacks[cite: 2].

Business & Operational Impact

  • Unauthenticated RCE: Complete compromise of host integrity, confidentiality, and availability[cite: 2].
  • Pivoting Foothold: Enables frictionless lateral movement and worm-like self-propagation[cite: 2].
  • Ransomware Exposure: Susceptible to automated commodity exploitation tools and worm payloads[cite: 2].
